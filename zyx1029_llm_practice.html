MODULE · 01

AI 客服 · 服务商切换

API 切换

对话页顶部放一个 下拉框，在「硅基流动」与「七牛」之间切换。 模型地址、模型名与密钥全部由后端从环境配置读取，前端只传提供方标识， 因此换服务商不需要改页面代码，也不会把 Key 暴露到浏览器。

验证要点

  • 切换下拉框后，页面状态栏显示当前提供方与对应模型名。
  • 同一句问题在两个服务商下都能正常回复，说明后端路由生效。
  • 切换服务后自动开启新会话，避免不同服务商的历史消息互相串联。
  • 浏览器网络面板中看不到任何 API Key，只有本项目的接口地址。

对应页面：chat.html（硅基流动）· service.html（七牛在线客服）

硅基流动 · 对话 localhost:8029/chat.html 七牛 · 对话 localhost:8029/service.html
MODULE · 02

知识库 · 上传与检索验证

RAG

自己选的文档上传后在服务端解析切块入库，支持 TXT / MD / CSV / DOC / DOCX / PPT / PPTX / PDF。 提问时先检索出相关片段作为参考资料，再交给大模型组织回答， 页面下方会列出引用来源；文档里没写的内容不编造。

验证要点

  • 上传成功后，文档数与片段数同步增长，列表出现新文件名。
  • 询问文档内的问题（如营业时间）能得到与原文一致的答案。
  • 回答附带检索来源片段，可核对答案确实来自上传内容。
  • 询问文档之外的信息时，模型明确说明资料中未提及。

对应页面：knowledge.html · 检索片段随回答返回

上传文档 · 入库 localhost:8029/knowledge.html 提问 · 检索验证 localhost:8029/knowledge.html
MODULE · 03

图像识别 · 图片理解与文字提取

Vision

选择本地图片后先预览再识别，调用视觉模型 Qwen3-VL-32B-Instruct 描述画面内容并提取图中文字。 支持 JPG / PNG / WEBP，建议 5MB 以内；图片只随本次请求传输，不落盘保存。

验证要点

  • 选择图片后预览区立即显示图片，未选图时有占位提示。
  • 识别结果与画面内容一致，文字提取能还原图中主要文字。
  • 可以继续追问细节，模型保留本次图片上下文。
  • 刷新页面后预览与结果清空，说明服务端没有留存图片。

对应页面：vision.html · 模型：Qwen3-VL-32B-Instruct

上传图片 → 识别结果 localhost:8029/vision.html
MODULE · 04

语音识别 · 录音转文字

ASR

既可以网页录音，也可以上传已有音频。录音时显示波形与计时， 前端统一转换为 16kHz WAV 后再送七牛 qwen3.8-omni-flash 识别； 麦克风下拉框可避开虚拟声卡，避免录到无声轨。

验证要点

  • 录音时有实时波形与计时，停止后可直接播放试听。
  • 中文短句识别结果与口述内容基本一致，标点基本正确。
  • 识别完成后可一键复制文本，清空按钮能复位界面。
  • 改用上传音频同样能识别，说明两种输入走同一条链路。

对应页面：speech.html · 模型：qwen3.8-omni-flash

录音 → 转文字 localhost:8029/speech.html
